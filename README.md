💻 Frontend Setup
1.   Open the project in your favorite code editor ✨
2.   Open the terminal 📂
3.   Navigate to the src folder: cd src
4.   Install the required dependencies 📦: npm install
5.   Start the frontend server 🚀 (default Vite port: 5173): npm run dev

🖥️ Backend Setup
1.   In a new terminal, move to the server folder: cd server
2.   Install backend dependencies 🔧: npm install
3.   Start the backend using nodemon (running on port 4001) 🔁: nodemon app.js

🎉 The application is now live and kicking! (●'◡'●)✨
